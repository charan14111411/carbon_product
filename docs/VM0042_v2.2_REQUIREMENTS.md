# VM0042 v2.2 — requirements the platform must implement

Source: Verra, *VM0042 Improved Agricultural Land Management*, v2.2, 21 October 2025
(https://verra.org/wp-content/uploads/2024/09/VM0042v2.2.pdf). Page numbers below are the PDF's
printed page numbers. **This file is the authoritative engineering reference** — every rule value the
platform ships with must cite a section/page from here, and every equation must carry its number.

Where the methodology says "must", the platform enforces (blocks). Where it says "should"/"recommended",
the platform warns.

---------------------------------------------------------------------------------------------------
## 1. Structure (§1, §8.1 p.19–23)

* Three quantification approaches (QA), chosen **per pool/source**; same approach in baseline & project
  for a given quantification unit (QU). Subdivisions using different QAs are stratified & accounted separately.
  * **QA1 Measure & Model** — process model (VMD0053), SOC remeasured ≤ every 5 years for true-up.
  * **QA2 Measure & Re-measure** — direct SOC measurement; baseline measured at **baseline control sites**. SOC only.
  * **QA3 Default factors** — fossil fuel CO2, liming CO2, CH4 (enteric, manure, burning), N2O (fertilizer,
    N-fixing, manure, burning) — IPCC 2019 Refinement.
* Table 5 allowed approaches: SOC → QA1/QA2; fossil fuel, liming → QA3; soil methanogenesis CH4 → QA1;
  enteric/manure/burning CH4 → QA3; fertilizer/N-fixing/manure N2O → QA1 or QA3; burning N2O → QA3.
* Project area divided into **quantification units** (more homogeneous than whole area; nested/staged allowed);
  each QU divided into **strata** (stratified random sampling is **required**, §8.2.1.2). Strata, their area
  and sampling points reported in a spreadsheet annex **at every verification**.
* Results are quantified **per year** (vintage) when a verification period spans several calendar years.
* Hectares are the reporting unit (footnote 12).

## 2. Applicability (§4 p.9–11) — enrolment must check

1. Project introduces practice change in ≥1 category: fertilizer mgmt, water/irrigation, tillage/residue,
   crop planting & harvesting (agroforestry, rotations, cover crops), grazing. (Appendix 1 list.)
2. Quantitative adjustments must **exceed 5 %** of the pre-existing value (average over the look-back period).
3. Land is **cropland or grassland** at project start and remains so (exceptions: planned temporary grassland in
   ICLS with long-term plan; one-time grassland↔cropland conversion on degraded land per Appendix 2).
4. QA1 models: public, peer-reviewed, versioned, validated per VMD0053; same model/parameters in baseline & project.
5. **Not applicable** if the area was **cleared of native ecosystems within 10 years** before project start.
6. Not applicable if the activity is expected to cause a sustained productivity reduction > 5 %, as demonstrated
   by peer-reviewed and/or published studies in the region or a comparable region (an ex-ante test).
7. Biochar application is not the project activity; if biochar is applied, its total organic carbon
   (VM0044 §8.2.2.1/8.2.2.2) **must be subtracted** from project SOC stock change at each verification.
8. Not applicable on **wetlands** (artificially flooded crops OK if nearby wetland hydrology unaffected).

## 3. Boundary (§5 p.11–13)

* Pools: SOC **must** be included (never de minimis). Above-ground woody biomass required if project reduces it,
  else optional; below-ground woody optional. Non-woody biomass, dead wood, litter, wood products excluded.
* Sources (Table 3): fossil fuel CO2 S*, liming CO2 S*, soil methanogenesis CH4 S*, enteric CH4 (yes if livestock),
  manure CH4 & N2O (yes if livestock), fertilizer N2O (yes if fertilised in baseline or more N in project),
  N-fixing N2O (yes if N-fixers planted), burning CH4/N2O S*, burning CO2 excluded (counted as stock change),
  woody biomass CO2 S*. S* = must include if project increases emissions by > 5 % vs baseline; may include if
  the project reduces them.
* **De minimis**: omitted decreases/increases together < **5 %** of total GHG benefit may be set to zero
  (CDM significance tool). Applies to project and leakage sources.

## 4. Baseline scenario (§6 p.13–16)

* Baseline = continuation of pre-project practices. For **each QU** build an annual **schedule of activities**
  from a **historical look-back period of x ≥ 3 years that includes at least one complete crop rotation**
  (t = −1 … −x). Schedule repeats every x years from t = 1 through the first baseline period (footnote 8 example).
* **Baseline reassessment every 10 years** (recommended every 5 years), using sub-national production data from
  the last 5 years; if the crop is no longer produced regionally, a new schedule from written agronomist
  recommendations; where a range is given, choose the most conservative value.
* **Table 4 minimum specifications per year** (qualitative → quantitative):
  * Crop planting & harvesting: crop type(s) → planting date, harvest/termination date, yield.
  * N fertilizer: manure Y/N, compost Y/N, synthetic N Y/N → application rates (N rate for synthetic).
  * Tillage/residue: tillage Y/N, residue removal Y/N → depth, frequency, % soil disturbed, % residue removed.
  * Water: irrigation Y/N, flooding Y/N → irrigation rate.
  * Grazing: grazing Y/N, animal type, harvesting/mowing Y/N → stocking rate, harvest frequency.
  * Liming: limestone/dolomite Y/N → application rate.
* **Box 1 data-source hierarchy** (qualitative info needs a **signed attestation** from farmer/landowner):
  1. Historical management records with documented evidence for the sample field and period t = −1 … −3
     (logs, receipts, equipment/sensor files) or remote sensing;
  2. Historical management plans with evidence for t = −1 … −3 (conservative value if a range: lowest baseline
     emissions / highest baseline stock change);
  3. Signed farmer attestation (must not deviate significantly from comparable evidence; VVB judges);
  4. Regional (sub-national) averages from census data from within the 20 years before project start **or the
     10 most recent iterations of the dataset, whichever is more recent**, + attestation.
  Every baseline value must record which tier it came from.

## 5. Additionality (§7 p.17–19)

1. **Regulatory surplus** per VCS Standard.
2. **Barrier analysis** — Step 2 of VT0008.
3. **Common practice** — adoption rate of the individual or stacked practice must be **< 20 %** in the region
   (stratified to state/province; justified alternatives allowed). Evidence: census/government, peer-reviewed,
   independent research, industry reports; else signed attestation of a qualified independent local expert
   (with qualifications and methods). If > 20 % (common practice is *defined* as > 20 % adoption, p.17, while
   Step 3.1 requires *lower than* 20 %, p.18 — treat exactly 20 % as not demonstrated) or data unavailable →
   Step 3.2 = VT0008 Step 4c: identify an essential distinction; N_all and N_diff sources must cover the same
   geographic area (the project region); F = 1 − N_diff / N_all on a land-area basis must be < 20 %; the
   N_all − N_diff > 3 rule does not apply. Example (p.19): adoption 22 % per census on ≈ 2 M ha (N_all);
   seed subsidy accessed on 1.7 M ha (N_diff) → F = 15 % → not common practice.

## 6. Baseline control sites (QA2) (§8.2 p.25–27)

* Within **250 km** of linked QU; one site may serve several QUs if it meets criteria for each.
* **At least 3 control sites** across the project (more reduce uncertainty, esp. < 10); **≥ 1 control site per
  stratum** or control site stratified like its QU. Location constant for project lifetime; large enough to
  avoid edge effects. Managed per the baseline schedule of activities.
* **Table 7 similarity criteria** (all must hold):
  * Topography: same most-frequent slope class (Appendix 5 Table 10); if the control site is hilly/steep/very
    steep, aspect within 30° of the cardinal direction of the linked QU.
  * Soil texture to depth of project boundary (min. 30 cm): **average** texture in the same FAO textural class as
    the QU's average texture (determine per horizon where texture differs markedly within 0–30 cm).
  * Soil group: same WRB reference soil group.
  * Average SOC % by dry weight **to depth of project boundary (min. 30 cm)**: not significantly different from
    the QU mean at **90 % confidence**.
  * Historical ALM same as QU for ≥ **5 years** before start: tillage (Y/N and type: no/conservation/full),
    residue removal, crop type — a crop of the same functional group only **where the QU crop cannot be matched**
    (Table 7 note e) — manure, compost, irrigation. Evidence per Box 1.
  * Historical land cover: if converted ≤ 50 years before start, converted from same major land cover within ±10 years.
  * Same terrestrial ecoregion (WWF); same IPCC climate zone.
  * Mean annual precipitation within **±100 mm** (station ≤ 50 km or synthetic station).
* **Appendix 5 Table 10 slope classes** (%): nearly level 0–3; gently sloping/undulating 4–8;
  strongly sloping/rolling 9–16; moderately steep/hilly 17–30; steep 31–45; very steep > 45.
* Climate model inputs (QA1): closest continuous weather station **≤ 50 km** or synthetic station.

## 7. Soil sampling & analysis (§8.2.1 p.27–37)

* Stratified random sampling **required**; grid/linear not recommended. Report stratification factors.
* Sample locations **georeferenced**; **intended and actual** location both recorded.
* Sampling & re-sampling in the **same season**.
* With organic amendments: sample as late as possible after previous application / as early as possible before next.
* **At least 3–5 composite samples *should* be taken per stratum** (for true-up or QA2) — p.30 wording is "should".
  Pre-sampling of 5–10 per stratum may estimate variance (§8.2.1.3(10) p.33).
* Optional power analysis (§8.2.1.3(11) p.33–34) — **Eq. 1** `MDD ≥ S/√n × (t_α,υ + t_β,υ)`,
  **Eq. 2** `n ≥ (S × (t_α + t_β) / MDD)²` (t_α two-sided, α often 0.05; t_β one-sided, power e.g. 90 %).
* Composited cores from same depth, fully homogenised. Clear surface organic material. Soil mass excludes
  > 2 mm particles and plant material (2 mm sieve). SOPs consistent for the project lifetime.
* **Ship within 5 days** of campaign completion ("must"); store protected; refrigerated/dried not frozen;
  refrigerated storage before analysis **should not exceed 3 months** ("should").
* **ESM basis is mandatory** for reporting SOC stock changes (QA1 & QA2) — Ellert & Bettany 1995,
  Wendt & Hauser 2013 (cubic spline), von Haden 2020. Report to **≥ 30 cm** (or bedrock/hardpan, documented);
  sample deeper than 30 cm to avoid extrapolation; **at re-sampling ≥ 2 depth increments**; recommended
  0–30 & 30–50 cm. Reference ESM must cover the sample with the highest measured soil mass.
  Where bulk density was measured at fixed depth, mass corrections may be applied to meet ESM.
* **Eq. 3** `M_SOC(kg/ha) = (M_sample(g) / (π (D/2)² × N)) × 10 000 × OC(g/kg)` — D probe inner diameter (mm),
  N cores composited. Cumulative mass summed over increments. Unit note: × 10 000 turns g/mm² into **Mg/ha**
  (the PDF labels it "g/mm² to kg/ha"); Mg/ha × g/kg gives kg/ha, so the equation as printed is correct.
  Worked example (Figure 3, p.36–37; D 21.5 mm, N 4): point 1 283.2 g @ 24.29 g/kg → 1950 Mg/ha, 47.36 Mg C/ha
  (+ 189.2 g @ 12.68 → 1303 Mg/ha, 16.52); point 2 222.7 g @ 28.77 / 144.3 g @ 10.65 → 1534 / 994 Mg/ha;
  point 3 217.5 g @ 20.68 / 143.5 g @ 11.28 → 1498 / 988 Mg/ha. At the 0–1950 Mg/ha ESM reference (cubic spline)
  the points hold 47.36, 49.9 and 36.8 Mg C/ha.
* **Eq. 4** (QA1 model input) `SOC_model(t/ha) = 100 × BD_corr × d × OC`, BD_corr = fine-fraction BD after
  subtracting coarse mass. OC must be a mass fraction (g/g) for t/ha; the parameter table (p.97) gives OC in g/kg
  for Eq. 3 and 4 — with g/kg divide by 1000.
* SOC analysis: **dry combustion (Dumas) recommended**; proximal sensing allowed (MIR, NIR, Vis-NIR, LIBS, INS)
  per Appendix 4; **Walkley-Black and LOI not recommended** (only where no other method available).
  Lab ISO/IEC 17025 where possible; **same lab for the project lifetime — change requires justification**;
  lab reports analytical error, internal QC, round-robin (NAPT/GLOSOLAN).
* Bulk density: core, excavation or clod method (ISO 11272:2017); excludes > 2 mm & plant material.
  BD, soil mass and SOC samples taken at the same time, within a few metres of the previous point.
* Digital soil mapping (remote sensing) only via **VT0014**; remote-sensing SOC content otherwise not allowed
  (Appendix 4 footnote 59).

## 8. Emission equations — QA3 (§8.2.3–8.2.11 p.38–47; parameters §9)

All emissions are areal means (t CO2e/ha) per QU i and year t; project uses the same equations with *wp*.

* **Fossil fuel** Eq. 6 `CO2_ff = Σ_j EFF_j / A_i`; Eq. 7 `EFF_j = FFC_j (L) × EF_CO2,j`.
  EF gasoline **0.002810**, diesel **0.002886** t CO2e/L (p.102, IPCC 2019 Vol 2 Table 3.3.1).
* **Liming** Eq. 8 `CO2_lime = EL / A_i`; Eq. 9 `EL = (M_limestone × 0.12 + M_dolomite × 0.13) × 44/12`
  (EF t C/t, p.103). Oxides/hydroxides excluded.
* **Soil CH4** (QA1) Eq. 10 `GWP_CH4 × f(CH4_soil)`.
* **Enteric CH4** Eq. 11 `(GWP_CH4 × Σ Pop_l × EF_ent,l / 1000) / A_i` (EF kg CH4/head/yr, IPCC Tables 10.10/10.11).
* **Manure CH4** Eq. 12 `GWP_CH4 × Σ(Pop × VS × AWMS × EF_CH4,md) / (10⁶ × A_i)`; Eq. 13 `VS = VS_rate × W/1000 × 365`.
* **Burning CH4** Eq. 14 `(GWP_CH4 × Σ MB_c × CF_c × EF_c,CH4 / 10⁶) / A_i`.
* **Soil N2O** QA1 Eq. 15; QA3 Eq. 16 `N2O_soil = N2O_fert + N2O_md + N2O_Nfix`.
* **Fertilizer N2O** Eq. 17 direct + indirect; Eq. 18 `direct = (FSN + FON) × EF_Ndirect × 44/28 × GWP_N2O / A_i`;
  Eq. 19 `FSN = Σ M_SF × NC_SF`; Eq. 20 `FON = Σ M_OF × NC_OF`; Eq. 21 `indirect = (volat + leach)/A_i`;
  Eq. 22 `volat = (FSN × Frac_GASF + FON × Frac_GASM) × EF_Nvolat × 44/28 × GWP`;
  Eq. 23 `leach = (FSN + FON) × Frac_LEACH × EF_Nleach × 44/28 × GWP`.
  Frac_LEACH (IPCC default) 0.24 in wet climates / dry irrigated (non-drip), else 0 (p.121).
* **N-fixing N2O** Eq. 24 `F_CR × EF_Ndirect × 44/28 × GWP / A_i`; Eq. 25 `F_CR = Σ MB_g × N_content,g`.
* **Manure deposition N2O** Eq. 26 total = direct + indirect; Eq. 27 direct `Σ F_manure × EF_N2O,md × 44/28 × GWP /
  (1000 A_i)`; Eq. 28 `F_manure = Pop × Nex × AWMS × MS` (kg N, Nex in kg N/head/yr); Eq. 29 indirect
  `(volat + leach)/A_i`; Eq. 30 `volat = F_manure × Frac_GASM × EF_Nvolat × 44/28 × GWP`; Eq. 31
  `leach = F_manure × Frac_LEACH × EF_Nleach × 44/28 × GWP`. Eq. 30/31 are printed without the /1000 of Eq. 27
  although F_manure is in kg N — divide by 1000 for t CO2e. Leach = 0 where annual precipitation < PET unless
  irrigated (p.47). MS default 1 allowed (p.91).
* Eq. 12 defines VS per head per **day**, but Eq. 13 (`× 365`) yields kg VS/head/**yr** — use Eq. 13's output.
* **Burning N2O** Eq. 32.
* **GWP**: CH4 **28**, N2O **265** (IPCC AR5, p.87, p.89) — applied per current VCS Standard.
* **Emission-factor hierarchy** (§8.1 p.21–22, §8.3): (1) project-specific peer-reviewed (Web of Science SCI),
  (2) robust alternative source with evidence, (3) IPCC 2019 Tier 2 derived from project activity data,
  (4) IPCC Tier 1/1a with justification. **Conservative choice** (§8.6.3 p.81): when project emissions
  decrease vs baseline use the **lowest** value in the EF uncertainty range for both scenarios; when they
  increase use the **highest** (e.g. EF_Ndirect wet climate 0.016, range 0.013–0.019).
* Where an activity is not practised, the equation element is not required (input zero).

## 9. Leakage (§8.4 p.50–53)

* **Organic amendments** Eq. 33 `LE_OA,t = Σ_l (M_OA,l,t × CC_oa × 0.12 × 44/12)` for **new or additional**
  manure/compost/biosolids **imported** into the project that were not applied in the look-back period — unless
  (1) produced on-site within the project area, (2) diverted from an uncontrolled anaerobic lagoon/pond/tank/pit
  without CH4 recovery, or (3) documented as not previously used as a soil amendment. 0.12 = manure C retention
  (Maillard & Angers 2014).
* **Livestock** (§8.3 p.48): where livestock are in the baseline, the project must use **at a minimum the average
  livestock value from the look-back period**. **Displacement** (§8.4.2 p.52): if the population declines, either
  (a) use the baseline population in project emissions and quantify leakage via VMD0054 (Eq. 36), or (b) show that
  commodity production did not decrease and livestock was slaughtered, not displaced (then LK_disp = 0).
* **Production declines** (§8.4.3): VMD0054 with Eq. 34 `l = FP − LM`, Eq. 35 `AL = MAX(Σ INL, 0)`,
  Eq. 36 `LK_disp,t = MAX(0, LK_t − LK_prior) / years`.
* **Biomass residues diverted from energy use** (§8.4.4): CDM TOOL16 → LE_BR,t.
* Leakage sources < 5 % of net ERRs may be de minimis.

## 10. Net reductions & removals (§8.5 p.54–62) — the engine must implement exactly

Indicator `I(ΔCO2_wp) = 1 if Σ_{1..t} ΔCO2_wp,t > 0 else 0` (cumulative project stock change).

* **Eq. 37**
  `ER_t = I × (ΣΔE + MIN(0,ΔCO2_wp,t) − MIN(0,ΔCO2_bsl,t))`
  `     + (1−I) × (ΣΔE + MIN(0,ΔCO2_wp,t) − MIN(0,ΔCO2_bsl,t) + MAX(0,ΔCO2_wp,t) − MAX(0,ΔCO2_bsl,t))`
  where `ΣΔE = ΔCO2_ff + ΔCO2_lime + ΔCH4_ent + ΔCH4_md + ΔCH4_bb + ΔCH4_soil×(1−UNC_CH4) + ΔN2O_soil×(1−UNC_N2O) + ΔN2O_bb`
  (emission reductions = baseline − project; UNC only on QA1-modelled CH4/N2O soil fluxes).
* **Eq. 38** `ER_NET = ER − LK_ER`; **Eq. 39** `LK_ER = (LE_OA + LE_BR) × ER/(ER+CR)`. Only LE_OA and LE_BR
  appear in Eq. 39/42; LK_disp (Eq. 36) is not routed into Eq. 38–43 by the PDF (gap — deducting it with the same
  allocation is a conservative interpretation and must be stated as such). Eq. 39/42 are undefined for
  ER + CR = 0 and give a negative share when ER or CR < 0.
* **Eq. 40** `CR_t = I × (MAX(0,ΔCO2_wp,t) − MAX(0,ΔCO2_bsl,t))`.
* **Eq. 41** `CR_NET = CR − LK_CR`; **Eq. 42** `LK_CR = (LE_OA + LE_BR) × CR/(ER+CR)`.
* **Eq. 43** `ERR_NET = ER_NET + CR_NET`.
* **Eq. 44** `ΔCO2_bsl,t = ΔCO2_soil,bsl,t × (1 − UNC_CO2 × I_soil) + ΔC_TREE,bsl + ΔC_SHRUB,bsl`
  **Eq. 45** `ΔCO2_wp,t  = ΔCO2_soil,wp,t × (1 − UNC_CO2 × I_soil) + ΔC_TREE,wp + ΔC_SHRUB,wp`
  with `I_soil = +1 if ΔCO2_soil,wp − ΔCO2_soil,bsl ≥ 0 else −1` (so the multiplier exceeds 1 and adds to
  losses when the project does worse than baseline — conservative).
* **Eq. 46/47** `ΔCO2_soil,bsl|wp,t = Σ_i ((SOC_i,t − SOC_i,t−x) × 1/x) × A_i` — **annualised over the
  verification period length x**; SOC in t CO2e/ha (×44/12). QA2: compare each QU with its linked control
  site(s) (mean per "project site–control site" combination); divide by number of years between measurements.
* Eq. 48–51 tree/shrub biomass (CDM A/R tools); Eq. 52 `ΔCO2_ff = Σ(bsl − wp) × A_i`; Eq. 53 liming;
  Eq. 54–57 CH4; Eq. 58–59 N2O — all `Σ_i (baseline areal mean − project areal mean) × A_i`.
* **Negative results are not floored** (losses reported; UNC multiplier > 1 when project underperforms).

## 11. Uncertainty (§8.6 p.62–84)

* Deductions estimated **separately for each GHG source/pool** over the verification period.
* **QA1 analytical**: model prediction error Eq. 60–61 (`s²_model,Δ = 2 s²_model (1 − ρ)`), sampling error
  **Eq. 62** `s²_sampling = Σ_h A_h²/(n_h(n_h−1)) × Σ_ip (Δ_h,ip − mean_h)²`, combined **Eq. 63**
  `s²_mean = s²_sampling / A² + s²_model`, area-weighted model error **Eq. 64** `s²_model = Σ_h (A_h²/A²) s²_model,h`.
  QA1 Monte Carlo Eq. 65–69 (L 500–1000 draws suggested; MC error factor √(1+1/L)). True-up every 5 years (§8.6.1.3).
* **QA2 (conventional lab)**: **Eq. 70** `s²_mean = (1/A²) Σ_h s²_ΔSOC,h`, `s²_ΔSOC,h = s²_wp,h + s²_bsl,h`
  (project/control covariance conservatively excluded — independent), area-weighting uses project strata areas.
  **Eq. 71** `s²_ΔSOC,wp,h = s²_f + s²_s − 2 COV(f,s)` with
  `s²_f = A_h²/(n_h(n_h−1)) Σ (SOC_ip,f − mean_f)²` (same for start s) and
  `COV = A_h²/(n_h(n_h−1)) Σ (SOC_ip,s − mean_s)(SOC_ip,f − mean_f)` — same points visited at both times.
  (Measurement error with ESM + dry combustion by a proficient lab assumed negligible.)
* **QA2 proximal sensing** Eq. 72 (MC, p.78–79) or **Eq. 73** (p.80) frequentist spectroscopy model error from a
  random **10–15 % of samples analysed by dry combustion** (p.78): `s²_model = A²/(tvd−1) Σ (error_pvd − mean error)²`.
* **Deduction Eq. 74** `UNC_t (%) = (√s²_mean / mean_ERR) × 100 × t_0.667` — one-sided Student t at
  **66.7 %** with df appropriate to the design (PDF: "≈ 0.4307" at large n; note 0.4307 is the 2/3 quantile —
  the 0.667 quantile is 0.4316). Applied as a fraction in Eq. 44/45 (SOC) and Eq. 37 (CH4/N2O soil).
* **QA3**: use the conservative end of the EF uncertainty range (see §8); sampling error only if management
  data not collected across all QUs.
* Appendix 6: multi-stage (landowner → field PPS → within-field strata → points) estimators A6.1–A6.9.

## 12. VCU calculation (§8.7 p.84–85)

* **Eq. 75** buffer on reductions:
  `Bu_ER,t = I × (MIN(0,ΔCO2_wp,t) − MIN(0,ΔCO2_bsl,t)) × NPR% + (1−I) × (MIN(0,ΔCO2_wp,t) − MIN(0,ΔCO2_bsl,t) + MAX(0,ΔCO2_wp,t) − MAX(0,ΔCO2_bsl,t)) × NPR%`
* **Eq. 76** buffer on removals: `Bu_CR,t = I × (MAX(0,ΔCO2_wp,t) − MAX(0,ΔCO2_bsl,t)) × NPR%`
  → **buffer applies only to carbon-stock changes, not to non-CO2 / fossil / liming reductions.**
* NPR% from the **VCS AFOLU Non-Permanence Risk Tool** (latest version).
* **Eq. 77** `VCU_ER = ER_NET − Bu_ER`; **Eq. 78** `VCU_CR = CR_NET − Bu_CR`; **Eq. 79** `VCU = VCU_ER + VCU_CR`.

## 13. Monitoring (§9 p.86–137)

* Parameter tables list, for every parameter: unit, equations, source, method, frequency, QA/QC.
  The platform must store, for each parameter used: value, unit, source (Box 1 tier / reference), date, evidence.
* SOC measured **at least every 5 years** (QA2: before each verification if more frequent).
* EF sources reviewed every 5 years and updated when better data available.
* ALM practice data (project): farmer **signed attestation** + documented evidence for quantitative values.
* Project area A and QU areas A_i from geo-registered GIS; convert other units to hectares.
* **Monitoring plan** must contain: tasks; accounting boundary (spatial, differences by QA); parameters;
  data collection & sample designs; control site management plans (location, boundaries, Table 7 demonstration);
  **10-year baseline re-evaluation plan**; QA/QC procedures; **data archiving — kept ≥ 2 years after the end of
  the last crediting period**; roles & responsibilities; modelling plan (QA1).
* Verra **templates** (ERR quantification spreadsheet, model validation report, IME assessment) must be used
  for validation/verification documents.

## 14. Appendix 4 — proximal sensing (p.152–157)

* Technology proven in ≥ 3 peer-reviewed articles; calibration against dry combustion with matching site
  characteristics; methods open to the VVB (no IP restriction); device-to-device calibration.
* Monitoring plan items: SOPs, interference strategies, instrument/spectral range, preprocessing, model type,
  randomised split (e.g. 70/30 or k-fold), representativeness (SOC, clay, Munsell colour, amendments),
  metrics (**RMSE, R², RPIQ, bias, Lin's CCC**), PPD approach or 10–15 % dry-combustion check, unbiased selection.
* Method criteria: INS (inorganic C accounted, scintillator types, PFTNA); LIBS (dry ≥ 24 h at 40 °C or 48 h air,
  acid-wash carbonates, mill, pellet, laser parameters, chemometrics); MIR/NIR (air/oven dry, < 2 mm, protocols,
  spectral libraries).
